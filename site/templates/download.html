Download and install

Quirewright is packaged for Linux. The libraries it uses also run on Windows and macOS and the source install should work there, but neither platform has been tested.

AppImage

A single file for x86_64 Linux. Download it from the latest release, then:

chmod +x Quirewright-*.AppImage
./Quirewright-*.AppImage

Flatpak

Build from the manifest in the repository (sandboxed, with the Qt base app from Flathub):

flatpak run org.flatpak.Builder --user --install \
  --force-clean build-dir \
  packaging/flatpak/io.github.quirewright.Quirewright.yml
flatpak run io.github.quirewright.Quirewright

From source

Python 3.11 or newer. Tesseract is optional and only needed for OCR.

git clone {{repo_url}}.git
cd quirewright
python -m venv .venv
.venv/bin/pip install -e .
.venv/bin/quirewright file.pdf
