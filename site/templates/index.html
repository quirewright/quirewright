Everything a desktop PDF editor is expected to do

Built for the jobs people reach for a commercial editor to do: fix a figure, retype a line, fill and build forms, rearrange a document, lock it down and sign it.

Objects, not pixels

Select any path, text run, image or group straight on the rendered page. Move, resize, rotate, recolour, reorder, align and distribute, with full undo.

Node editing

Double-click a shape to edit its nodes and Bézier handles. Draw new rectangles, ellipses, lines and curves with the Pen tool.

Text in place

Edit a whole visual line even when the PDF split it into pieces, re-wrap paragraphs, change size and colour. Missing glyphs fall back to a bundled font and tell you so.

Forms that calculate

Drag out text fields, checkboxes, radios, lists and buttons. Add Acrobat-compatible calculation, format and validation scripts and preview them live.

Pages, properly

Rotate, reorder by drag, duplicate, insert blanks or pages from another file, extract, split, crop, label, number and watermark.

Secure and sign

Set user and owner passwords with AES-256, choose permissions, sign with a PKCS#12 certificate or a visible signature field, and verify what others signed.

Comments, find, OCR

Highlight, underline, strike out and add notes. Search across pages. Give scanned documents a searchable text layer with Tesseract.

Resources out

Browse and extract every image, font and attachment, attach your own files, edit metadata, redact, flatten, export pages as PNG, JPEG or SVG and save a smaller copy.

Made to be used

Light and dark themes that follow your desktop, document tabs, rulers, guides and snapping, a shortcut for every tool, and a searchable guide built in.

How it edits

Surgical changes to the content stream

Quirewright parses a page's drawing instructions itself, tracks the full graphics state, and rewrites only the bytes that produced the object you changed. Nothing is rasterised and nothing is regenerated, so the rest of the page renders identically in every viewer.

  • Paths are rewritten in their own user space, exact under any transform
  • Text blocks are regenerated with absolute positioning per run
  • Groups are form XObjects; enter and edit them, nested as deep as they go
Forms

Build, fill and script forms

Field properties live in the Inspector: name, value, options, caption, font, colours, borders and flags. Calculation, format and validation scripts use the same AFSimple_Calculate family that Acrobat understands, and Quirewright evaluates them locally so you see results as you type.

The name

Quire · wright

A quire is a gathering of folded sheets, the unit from which a bound book is assembled. A wright is a maker. The icon is three offset folded sheets with a bookbinder's awl.
